# Questão 04 — Operadores de Atribuição Composta e Precedência

## Pergunta

Os operadores de atribuição composta (`+=`, `-=`, `*=`, `/=`, `%=`) executam uma operação aritmética e uma atribuição simultaneamente. Determine quais serão os valores das variáveis `a`, `b`, `c` e `d` após a execução sequencial completa das seguintes instruções de inicialização e atribuição em C. Justifique seus cálculos apresentando a ordem de avaliação passo a passo:

```c
int a = 1, b = 2, c = 3, d = 4;
a += b + c;             // Valor final de a = ?
b *= c = d + 2;         // Valores finais de b e c = ?
d %= a + a + a;         // Valor final de d = ?
d -= c -= b -= a;       // Valor final de d, c e b = ?
a += b += c += 7;       // Valor final de a, b e c = ?
```

---

## Resposta

**Resultado final: `a = 19`, `b = 13`, `c = 7`, `d = 4`**

Abaixo o passo a passo de cada linha.

### Situação inicial

```
a = 1    b = 2    c = 3    d = 4
```

---

### Linha 1 — `a += b + c;`

A soma `b + c` tem precedência sobre o `+=`, então é resolvida primeiro. A linha equivale a `a = a + (b + c)`.

```
b + c = 2 + 3 = 5
a = 1 + 5 = 6
```

→ **a = 6**

---

### Linha 2 — `b *= c = d + 2;`

Aqui entra a regra mais importante da questão: **atribuição é associativa à direita**. Ou seja, o que está mais à direita resolve primeiro. A linha equivale a `b = b * (c = (d + 2))`.

```
d + 2 = 6
c = 6                 (e a atribuicao "devolve" o valor 6)
b = 2 * 6 = 12
```

→ **b = 12, c = 6**

Vale destacar: em C, uma atribuição não é apenas um comando — ela é uma expressão que **tem valor**. O valor de `c = 6` é o próprio `6`, e é isso que a multiplicação usa.

---

### Linha 3 — `d %= a + a + a;`

Equivale a `d = d % (a + a + a)`. Nesse ponto `a` já vale 6.

```
a + a + a = 18
d = 4 % 18
```

Como 4 é menor que 18, a divisão inteira dá 0 e o resto é o próprio 4.

→ **d = 4**

---

### Linha 4 — `d -= c -= b -= a;`

De novo, direita para a esquerda: `d -= (c -= (b -= a))`.

```
1) b -= a   →  b = 12 - 6 = 6      (devolve 6)
2) c -= 6   →  c =  6 - 6 = 0      (devolve 0)
3) d -= 0   →  d =  4 - 0 = 4
```

→ **b = 6, c = 0, d = 4**

---

### Linha 5 — `a += b += c += 7;`

Mesma lógica: `a += (b += (c += 7))`.

```
1) c += 7   →  c =  0 +  7 =  7    (devolve 7)
2) b += 7   →  b =  6 +  7 = 13    (devolve 13)
3) a += 13  →  a =  6 + 13 = 19
```

→ **a = 19, b = 13, c = 7**
