# Questão 05 — Avaliação de Expressões Lógicas e Relacionais

## Pergunta

Determine o resultado lógico (1 para verdadeiro, 0 para falso) de cada uma das expressões relacionais e lógicas a seguir, assumindo que as variáveis foram inicializadas como:

```c
int i = 1, j = 2, k = 3, n = 2;
float x = 3.3, y = 4.4;
```

| | Expressão |
|---|---|
| a | `i < j + 3` |
| b | `2 * i - 7 <= j - 8` |
| c | `-x + y >= 2.0 * y` |
| d | `x == y` |
| e | `!(n - j)` |
| f | `!n - j` |
| g | `i && j && k` |
| h | `i \|\| j - 3 && k` |
| i | `i < j && 2 >= k` |
| j | `i == 2 \|\| j == 4 \|\| k == 5` |

---

## Resposta

A regra que resolve quase tudo aqui: **aritmética vem antes de comparação, que vem antes dos operadores lógicos `&&` e `||`**. O `!` é exceção — tem precedência altíssima, maior que qualquer operador binário.

| Item | Expressão | Como chega lá | Resultado |
|---|---|---|---|
| a | `i < j + 3` | `j+3 = 5`, então `1 < 5` | **1** |
| b | `2 * i - 7 <= j - 8` | `-5 <= -6` é falso | **0** |
| c | `-x + y >= 2.0 * y` | `1.1 >= 8.8` é falso | **0** |
| d | `x == y` | `3.3 ≠ 4.4` | **0** |
| e | `!(n - j)` | `2-2 = 0`, e `!0` é 1 | **1** |
| f | `!n - j` | `!2 = 0`, então `0 - 2` | **-2** |
| g | `i && j && k` | todos diferentes de zero | **1** |
| h | `i \|\| j - 3 && k` | `1 \|\| (-1 && 3)` → `1 \|\| 1` | **1** |
| i | `i < j && 2 >= k` | `1 && 0` | **0** |
| j | `i==2 \|\| j==4 \|\| k==5` | nenhuma é verdadeira | **0** |

---

### Os itens que mais confundem

**Item (c) — sinal negativo unário**

`-x + y` significa `(-x) + y`, não `-(x + y)`. O menos unário gruda na variável antes da soma acontecer.

```
-3.3 + 4.4 = 1.1        (e não -(3.3 + 4.4) = -7.7)
2.0 * 4.4 = 8.8
1.1 >= 8.8 → falso
```

**Itens (e) e (f) — o par que a questão quer contrastar**

Essa dupla é o coração do exercício. A única diferença é o parêntese, e ele muda tudo:

```
!(n - j)   →  o parentese obriga a subtracao primeiro:  !(0) = 1
!n - j     →  o ! age antes, so sobre o n:  (!2) - 2  =  0 - 2  = -2
```

O item (f) é o único cujo resultado **não é 0 nem 1**. Isso acontece porque, apesar do `!`, o operador principal da expressão é a subtração — e subtração devolve um número qualquer, não um valor lógico.

Detalhe curioso: se esse `-2` fosse usado dentro de um `if`, ele seria considerado **verdadeiro**. Em C, tudo que é diferente de zero conta como verdadeiro.

**Item (h) — precedência entre `&&` e `||`**

O `&&` liga mais forte que o `||`, então a leitura correta é:

```
i || ((j - 3) && k)
```

E tem mais: como `i` vale 1, o C nem precisa avaliar o lado direito. Isso se chama **curto-circuito** — assim que o resultado já está garantido, o restante é ignorado.

**Item (d) — cuidado ao comparar decimais**

Aqui o resultado é 0 porque 3.3 e 4.4 são de fato diferentes. Mas fica o alerta: comparar `float` com `==` é arriscado em geral, porque números decimais têm pequenos erros de representação binária. Por exemplo, `0.1 + 0.2 == 0.3` dá **falso** em C. O jeito seguro é verificar se a diferença é pequena o bastante: `fabs(x - y) < 0.000001`.
